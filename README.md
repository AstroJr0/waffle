# 🧇 Waffle

> A minimal, self-sovereign proxy filter built out of practical necessity.

[![Host](https://img.shields.io/badge/Hosted_on-Codeberg-blue?logo=codeberg)](https://codeberg.org)
[![License](https://img.shields.io/badge/License-Apache_2.0-green.svg)](LICENSE)


## Why i made it

Waffle wasn't built to follow dev trends or impress corporate pipelines. It was built because I needed a lightweight, direct way to break bad digital habits, block distractions, and regain focus over my own environment. 

It started as a raw Python proxy server engineered to solve a personal friction point. It worked so well in my daily workflow that it became a core tool worth maintaining, evolving, and protecting. 


##  Features

- **Direct Site & Domain Filtering:** Intercepts unwanted connections cleanly before they hit your browser.
- **Zero Telemetry:** Designed strictly for localized control with no tracking or external reporting.
- **Lightweight Footprint:** Low resource overhead, running silently in the background.
- **Custom Rule Control:** Easy configuration setup to block, allow, or redirect host targets.
